# UI 与业务流程审查（2026-10-26）

> 方法：全部页面在 1440 宽度下截图逐页检查（销售 / 主管 / 管理员），并对照成熟 CRM 的通行做法：Twenty（布局与表格）、HubSpot（任务、商机阶段概率、报价文档）、Pipedrive（以「下一步行动」驱动的销售、停滞商机提醒）、Salesforce（联系人角色）、纷享销客 / 销售易（公海池、回款计划、客户转移）。

## 一、界面问题（看得见的毛病）

| # | 位置 | 问题 | 建议 |
|---|---|---|---|
| U1 | 所有表格 | 首列勾选框离面板左边缘只有约 8px，和表头图标、文字不对齐；**勾选后没有任何批量操作**，底部「已选 0 条」也没有用处 | 去掉勾选列；或做成真功能（批量导出、主管批量转移负责人） |
| U2 | 所有表格 | 最右侧多了一条空列（原来放「+」的列），看起来像布局没对齐 | 删除 |
| U3 | 所有输入框 | 聚焦时出现一圈很粗的灰色双层边框（边框加 3px 外环） | 改成细的单层聚焦边框 |
| U4 | 新建报销 | 「参与人」要手写「客户：xx；我方：xx」，「人数」也要单独填，两者容易对不上 | 客户方从该客户的联系人里勾选，我方从同事里勾选，再加「其他人数」；总人数自动计算 |
| U5 | 新建报销 | 必须先保存草稿才能上传票据，多了一步 | 选文件时自动创建草稿，一步完成 |
| U6 | 新建报销 | 客户招待的「关联客户」不是必填；表单里也没有「关联商机」（后端支持） | 客户招待时必填客户，选了客户之后可以选商机 |
| U7 | 新建客户 | 「行业」「规模」是自由文本，同一个行业会出现「法律」「律所」「法律服务」等多种写法，筛选和统计都会乱 | 改成下拉选项（行业字典、规模区间） |
| U8 | 商机看板 | 「我的商机」视图里每张卡片都重复显示负责人「张晨」；日期「11-30」没有说明是什么日期 | 「我的」视图隐藏负责人；日期标注「预计成交」 |
| U9 | 商机侧栏 | 「下一步建议」是一段固定文字，看起来像 AI 功能，其实不是 | 删除，或换成真正的「下一步行动」（见 B1） |
| U10 | 商机侧栏 / 客户详情 / 报价详情 | 字段都不能修改（金额、赢率、预计成交日、客户信息），后端其实已有修改接口 | 字段点击即可原地编辑（Twenty 的做法） |
| U11 | 客户详情 | 标签页只有「时间线 / 报价单」，没有「商机」「联系人」；联系人不能新增或修改 | 补商机、联系人标签页，联系人可以增删改 |

## 二、业务流程问题（和成熟 CRM 相比缺的东西）

| # | 问题 | 别人怎么做 | 建议 | 工作量 |
|---|---|---|---|---|
| B1 | **没有任务 / 下一步行动**。工作台原型里的「待办」被换成了「管道概览」；商机没有「下一次跟进时间」 | Pipedrive：每个商机必须有下一个计划活动，没有就标黄提醒；HubSpot：任务带到期时间和提醒 | 新增任务：关联客户或商机、到期时间、完成勾选；工作台显示「今天 / 逾期」；商机卡片显示下一步，没有下一步的高亮提醒 | 中 |
| B2 | **赢率靠手填**，加权金额不可信 | HubSpot：每个阶段设默认概率（例如方案报价 50%），切换阶段时自动带出 | 阶段默认概率写进 rules.yaml，切换阶段时自动更新，允许手动改 | 小 |
| B3 | **停滞商机没有提醒** | Pipedrive：「腐烂」商机，超过 N 天没有动静就标红 | 超过 14 天没有跟进的商机，卡片显示「已 N 天未跟进」 | 小 |
| B4 | **报价单发不出去**：「发送客户」只是改了状态，没有可以发给客户的报价文档；明细也不能手动调整 | HubSpot / Salesforce：生成带公司抬头的报价 PDF，可以调价、打折，有版本 | 生成可打印的报价单页面（浏览器打印成 PDF）；允许调整数量和折扣（超过 10% 走审批，规则已有） | 中 |
| B5 | **客户不能转移、没有公海** | 纷享销客 / 销售易：销售离职或长期不跟进，客户退回公海，主管可以重新分配 | 主管可以转移客户负责人（动态跟着转）；公海作为后续扩展 | 小～中 |
| B6 | **审批没有通知** | 所有 CRM 都有站内通知：待我审批、我的申请被通过或驳回 | 顶栏加铃铛：主管看到待审批，销售看到审批结果 | 小 |
| B7 | **联系人没有角色** | Salesforce：商机的联系人角色（决策人、影响者、使用者） | 联系人标注角色，商机侧栏显示关键人 | 小 |
| B8 | **新建客户不查重** | 所有 CRM 都会提示「已存在相似客户」 | 输入名称时实时提示相似客户（后端已有重名校验，只是报错时机太晚） | 小 |
| B9 | **合同没有回款计划** | 国内 CRM 普遍有回款计划和开票记录 | 合同下维护回款计划（期次、金额、日期），逾期提醒 | 中 |

## 三、建议的优先级（距 11.10 汇报还有约两周）
1. **必须改**（影响观感和演示）：U1–U4、U7、U9。
2. **建议做**（体现对销售业务的理解，答辩加分）：B1 任务与下一步、B2 阶段概率、B3 停滞提醒、B4 报价单打印与调价、B6 通知。
3. **可以放到后续**：B5、B7、B8、B9、U10、U11。
