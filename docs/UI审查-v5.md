## 通用规范（写进后续开发）

1. **说明类内容用悬浮卡片，不占整屏侧栏。** 侧栏只用于表单和详情；规则、格式、帮助这类「看一眼就走」的内容用 `InfoPopover`（悬停展开、可点击固定、Esc 关闭）。
2. **说明里要有具体数字，并且数字来自后端。** 前端只写文案，比例和阈值从 `/api/templates` 的 `rule_notes` 读取，避免文档和代码两套数字。
3. **涉及上传或填写的地方，给出样例。** 样例文件放在 `apps/web/public/samples/`，用 HTML 模板生成并带「样例」水印，不使用真实品牌、真实税号。
4. **列表里的异构数据要标出类型和处理方式**（如知识库里「哪些会入库」），不要让用户猜。
5. **截图走查要在真实镜像上做**：本轮有一次测试打在旧镜像上，看起来像代码没生效。
