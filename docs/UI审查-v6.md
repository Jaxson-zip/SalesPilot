## 二点五、AI 工作台追加（用户反馈）

| # | 问题 | 原因 | 处理 |

| 21 | 出方案「不像流式，一瞬间全输出」 | 后端本身是逐字推送的，但出方案在确认前**没有任何文字**：解析需求 → 配置 → 定价 → 毛利检查都是规则计算，0.15 秒内全部完成，方案卡片、物料清单、确认框同时弹出 | ① 新增 `explain` 节点：确认前由模型流式说明几档方案差别和推荐理由（无模型时用模板）。② 前端正文逐字显示（`useSmoothText`，模型一次吐一大段也能平滑），生成中卡片和确认框等这段话打完再淡入。③ 会话区跟随内容增长自动滚动（用户往上翻时不打扰）。④ 历史里确认前后两段 AI 消息合成一条 |
| 22 | 「新对话」栏和左侧导航贴在一起，像两列导航 | 页面里另开 240px 会话栏，和导航栏并排。先试过并进左侧导航，结果和「工作区」菜单混在一起更乱 | 改为**右侧弹出面板**：标题行「历史记录」打开，可搜索、按今天 / 昨天 / 近 7 天 / 更早分组，重命名、删除不变，选中或新对话后自动关闭；左侧导航只保留工作区菜单，页面只剩对话区。当前会话写在地址 `/ai?t=<id>`，刷新可恢复 |
