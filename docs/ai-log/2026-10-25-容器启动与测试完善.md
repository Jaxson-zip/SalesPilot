## 发现的问题与修正（校验与兜底）

| 问题 | 怎么发现的 | 原因 | 修正 |
|---|---|---|---|
| 网关容器启动即崩溃 | `docker compose up` 时 gateway 退出 | `.env` 中「空值 + 行尾注释」被 Docker Compose 当成值，超时参数变成了一段中文注释 | `.env.example` 不再写行尾注释；两个服务的配置开启 `env_ignore_empty`；补回归测试 |
| 方案卡片在回复里出现两遍 | 浏览器实测 | 毛利回退后 core 重新推送卡片，前端是追加而不是替换 | 同类型卡片只保留最新一份（`upsertArtifact`）+ 测试 |
| 确认卡片显示 `total_price 37200000`、`margin_rate 0.2944` | 浏览器实测 | 前端直接把原始字段名和值展示出来 | 新增 `interrupt-preview.ts`：隐藏内部 id，金额和比例格式化，字段改中文 + 测试 |
| 报价单结果显示成 JSON | 浏览器实测 | 前端缺少 `quote` 类型的卡片 | 新增 `QuoteCard`（编号、状态、金额、毛利，可点进详情） |
| 回复文字写「状态：draft」 | 浏览器实测 | 模板直接输出状态代码 | core 增加状态中文映射 + 测试 |
| `seed --with-kb` 打印一长串堆栈 | 首次导入数据 | 没配 Embedding 时向量化失败，日志用了 `exception` | 改为一行提示，说明之后如何补入知识库 |
| Git 在 Windows 把换行转成 CRLF | 提交时的警告 | `core.autocrlf=true` | 新增 `.gitattributes` 统一 LF，避免容器内脚本出错 |
