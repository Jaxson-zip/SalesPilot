## 发现的问题与修正（校验与兜底）

| 问题 | 怎么发现的 | 原因 | 修正 |
|---|---|---|---|
| **toast 里的「撤销」在侧栏打开时点不了** | Playwright 点「撤销」超时；在浏览器里用 `elementFromPoint` 检查，命中的是侧栏底栏 | Radix 模态侧栏给 body 加了 `pointer-events:none`，toast 继承后整条不可点；点到侧栏外还会让侧栏关闭 | 全局样式让 toast 恢复 `pointer-events:auto`；`SheetContent` 点到 toast 时不算「点外面」。这正是用户之前反馈的「点错了撤销不了」的另一半原因 |
| **偶发：选了票据却显示「还没有上传票据」** | Playwright 报销用例时过时不过；对照 core 日志，上传是 200，紧接着刷新的详情里却没有票据 | FastAPI 带 `yield` 的依赖默认在**响应发出之后**才执行 `commit()`，前端「写完立刻读」会读到提交前的数据 | `DbDep` 改为 `Depends(get_db, scope="function")`，先提交再返回；回归测试 `tests/unit/test_db_dep.py` 记录「处理 → 提交 → 发送响应」的顺序（去掉修复时该测试失败） |
| 完成任务后撤销提示不出现 | Playwright | 撤销提示写在 `mutate()` 的单次回调里，列表刷新导致组件重渲染后回调可能被丢弃 | 改为 `mutateAsync().then(...)` |
| 主管打开客户列表一片空白 | Playwright 转移负责人用例找不到客户；截图显示「我负责的 · 0」 | 主管一般不直接负责客户，默认视图却是「我负责的」 | 主管默认「团队客户」 |
| 动态里显示英文代码 `task_done` | 测试失败截图 | v3 新增的动作代码（`task_done` / `transfer` / 报价 `update`）没有中文 | 补文案；新增单元测试：契约 §0 动作代码表里每个代码都必须有中文 |
| AI 写的浏览器测试用了 `check()` 勾选任务 | Playwright 报「点击后状态没变」 | 任务勾选框是受控的（勾选后该行直接消失），不适合 `check()` | 测试改为 `click()` 后断言该行消失 |
| Windows 下用脚本改文件引入 CRLF | 提交前检查 | Python 文本模式在 Windows 写出 `\r\n` | 统一转回 LF |
