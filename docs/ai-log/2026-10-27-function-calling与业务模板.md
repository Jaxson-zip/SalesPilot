# function calling、差旅报销与业务模板（阶段 8）

- 日期：2026-10-27 ｜ 工具：Claude Code（单 agent）｜ 模块：core / gateway / web / tests

## 任务目标
1. 按《架构完成度与缺项说明》的顺序推进：远程仓库 → 模型 Key → **Agent 改为 function calling**（场景 3 硬要求）。
2. 用户新增要求：「需要给示例模板，比如报销的模板，还有那些需要说明，把它当成真正用得上的 CRM」。

## 做了什么

| 部分 | 内容 |
|---|---|
| Agent | `tool_agent` 改为 `bind_tools` 循环：只读工具直接执行；写工具（改阶段、提交报销、建任务、审批）先 interrupt 弹确认卡，确认后把结果作为 tool 消息交回模型继续；取消时告诉模型「用户取消」。router、需求抽取改为结构化输出。没有模型时全部回落关键词规则 |
| 工具 | 新增 `get_customer_context`（拿商机 / 联系人 id）、`list_pending_approvals`（主管）；按角色收窄工具（销售 9 个、主管 11 个、管理员 5 个只读）；幂等键、行业包由系统注入，不出现在给模型的工具定义里 |
| 模型可用性 | 网关没有可用模型时 core 不再每个节点都去调必然失败的接口（30 秒缓存）；新增 `GET /api/agent/models`，前端模型选择器显示「未配置」和「规则模式」 |
| 报销 | 差旅住宿按城市每晚标准校验（一线 ¥500 / 其他 ¥350，制度 3.2）；差旅交通填行程；只有客户招待显示参与人；新增迁移 0006 `expenses.details` |
| 模板 | `app/rules/templates.yaml` + `GET /api/templates`：报销模板与报销须知、跟进模板、常用下一步、输单原因、报价条款、按角色的 AI 示例问题；标准金额等数字由 `rules.yaml` 计算后填入 |
| 页面 | 新建报销「从模板开始」+「报销须知」；客户页跟进模板（模板没填写不能保存）；添加下一步、输单弹窗的常用选项；报价单打印页「条款与说明」；新增「使用说明」页 |

## 发现的问题与修正（校验与兜底）

| 问题 | 怎么发现的 | 原因 | 修正 |
|---|---|---|---|
| **欢迎页示例问题「承诺」了做不到的事** | 盘点工具清单时对照 | 「我这个月的提成大概多少」「哪些客户超过两周没有跟进」没有对应的工具，模型只能编 | 示例问题改为按角色从模板读取，只放工具真正能完成的问题；欢迎语同步修改 |
| **制度里有住宿标准，系统从来不校验** | 读《费用报销管理制度》对照 rules.yaml | 规则代码只实现了客户招待，其他类型「暂无限额」 | 实现住宿每晚标准，数字放 rules.yaml，补单元和接口测试 |
| 差旅报销也要填「客户方参与人 / 其他人数」 | 走查表单 | 表单不分类型 | 表单按类型显示字段，非招待人数固定为 1 |
| 主管说「通过那笔报销」AI 做不到 | 设计 function calling 时推演对话 | `decide_approval` 需要审批 id，但没有查待审批的工具 | 新增 `list_pending_approvals`；确认卡片显示单号和金额，主管能看清在批什么 |
| 修改 `tools/base.py` 时误删了半个文件 | ruff 报一批「未使用的导入」 | 第二次替换用了「从标记到文件末尾」，把 `run_tool` 等函数一起删掉 | `git checkout` 恢复后重新精确替换；以后脚本替换先断言目标唯一 |
| 端到端测试「request_id 透传到网关」失败 | API e2e | 新增的可用性缓存让对话不一定调网关；网关也只在 chat 调用时记 request_id | 网关中间件对每个请求记录 request_id；测试改走每次都会访问网关的 `/api/agent/models` |
| 网关日志里出现 `/v1/models 401` | 排查上一条时 | 以为 core 的密钥配错 | 对比容器内两边密钥哈希一致；401 来自测试里故意用错误 Key 的用例，属于正常 |
| AI 写的测试有 4 处选择器不精确 | Playwright 报 strict mode violation | 「取消」也匹配到「需求取消或无限期延后」；「保存草稿」也匹配到上传区的提示文字 | 改为 `exact: true` |
| 日期选择测试偶发失败 | 全量回归时 1 次 | 前一个日历收起动画没结束就打开下一个，页面上同时有两个日历 | 选完日期等日历消失再继续 |
| Windows 下脚本写入的字符串里 `\n` 变成真换行 | ruff / tsc 语法错误 | heredoc + Python 转义处理不一致 | 用编辑工具直接修正；含转义的替换改用编辑工具 |
