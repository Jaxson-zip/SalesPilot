# 悬浮说明卡片、上传格式说明与样例文件（阶段 10）

- 日期：2026-10-27 ｜ 工具：Claude Code（单 agent）｜ 模块：web / core

## 任务目标
用户反馈：「提成规则」弹出一个几乎空白的整屏侧栏，太丑；要求 UI 重新审计、说明改成悬浮设计，并补格式说明（发票样例、xlsx 文档之类的示例）。

## 做了什么

| 部分 | 内容 |
|---|---|
| UI 审计 | 三个角色、十几个页面逐个截图走查：只有「提成规则」是问题（四行空话 + 整屏侧栏）；行业包知识库列表看不出格式、也没有 PDF / Excel 的说明；报销上传区只说「支持 JPG / PNG / PDF」 |
| 悬浮说明 | 新增 `InfoPopover`（悬停 150ms 展开、移入卡片不收起、点击固定、Esc 关闭）和 `RuleHint`；提成规则、报价审批规则、报销标准三处改为悬浮卡片，显示**具体数字** |
| 规则数字 | 后端新增 `rule_notes`（`GET /api/templates`）：提成比例、毛利底线、折扣权限、有效期、招待与住宿标准全部由 `rules.yaml` 计算后填入，前端不写死 |
| 上传说明 | 上传区「格式说明与样例」：格式与大小、本类需要哪些票据、拍照要求、发票 / 小票样例缩略图（可查看、可下载） |
| 样例文件 | `scripts/samples/` 用 HTML 生成带「样例 · 非真实票据」水印的 PDF / PNG（虚构公司与税号，金额自洽：811.32 + 48.68 = 860，小票明细合计 860）；知识库样例 md / pdf / xlsx 从 core 复制到 `public/samples/` |
| 知识库 | 文档列表增加格式标和「配置数据 · 不入库」；「支持的格式与样例」悬浮卡片说明三种格式的处理方式和下载 |
| 其他 | 种子数据里的「海底捞福田店」改为「示例餐饮福田店」（避免使用真实品牌）；`formatBytes` 不再显示「10.0 MB」 |

## 发现的问题与修正（校验与兜底）

| 问题 | 怎么发现的 | 原因 | 修正 |
|---|---|---|---|
| 说明侧栏几乎空白 | 用户截图；审计截图确认 | 内容只有四行泛泛而谈，还占满整屏侧栏 | 改为悬浮卡片，并且把 `rules.yaml` 里的真实数字填进去 |
| 行业包知识库看不出格式 | 审计截图 | 列表只显示文件名和大小，`models.json` 和资料混在一起 | 加格式标和「配置数据 · 不入库」，并说明三种格式怎么处理 |
| 样例文件被浏览器缓存的旧版本影响 | 浏览器测试断言 `10 MB` 失败，页面显示 `10.0 MB` | 测试打在旧镜像上（只改了源码没重新构建） | 重新构建镜像后再跑；顺带发现 `formatBytes` 的格式问题，补回归测试 |
| 悬浮卡片定位超出屏幕 | 截图：知识库卡片右边被裁掉 | 卡片默认左对齐，而触发按钮在右侧 | 该处改为右对齐 |
| Playwright 找不到悬浮卡片 | 测试失败 | 卡片 portal 到 body，不在侧栏子树里 | 测试改用整页定位；同时让卡片有 `aria-label`，读屏可识别 |
| 样例发票标题换行 | 生成后查看图片 | 标题字号过大 | 调小字号并禁止换行 |
