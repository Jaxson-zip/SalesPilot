# 精简功能、补全链路、AI 会话留存

- 日期：2026-10-30 ｜ 工具：Claude Code（单 agent）｜ 模块：web / core / docs

## 任务目标
用户觉得项目「越做越臃肿、AI 味重」，要求先想清楚解决什么问题，再做减法；之后审查页面样式和主线链路是否闭环；最后要求 AI 工作台像 Codex 一样留存对话。

## 做了什么
| 部分 | 做法 |
|---|---|
| 功能清单 | `docs/功能清单与精简建议.md`：主线、用户、逐项保留 / 合并 / 收起建议 |
| 设置入口 | 管理员系统设置 9 个 → 5 个，合并入口顶部用标签页切换（`NavItem.children`） |
| 链路 | 商机详情补「跟单费用」和「这单赚多少」（报价毛利 − 预估提成 − 跟单费用） |
| 文案 | 行业包页、AI 首页压短；示例卡片 8 → 4 |
| 报价额外费用 | 草稿报价单可以自己加目录以外的费用（加急、差旅、第三方服务等），填名称、单价、成本、数量；计入总价和毛利，照常按规则判断是否要审批 |
| 自己出报价 | 不经过 AI 新建报价（选客户 / 商机、产品线，从产品目录加物料）；目录物料单价可改，改了显示原价、写进动态；预估毛利低于成本标红 |
| 驳回闭环 | 驳回必须写原因；报销被驳回后显示原因，可修改、补票据，在同一张单上重新提交 |
| 通知定位 | 任务通知打开所属商机 / 客户并高亮那条任务；修正商机链接参数名（原来只停在看板上） |
| 日报 | 没保存就离开先确认；内容暂存在浏览器里，回来自动恢复 |
| AI 会话 | 做方案、学习问答各一条当前会话，互不影响；只有点「新对话」才清空；切走或换模式时后台接着生成；刷新后回到上次的对话 |
| 商机出方案 | 点「出方案」直接开新对话发给 AI：带上商机、预计金额和这个商机最近的跟进记录，AI 从里面拆需求，缺什么再问（原来只预填输入框，还要自己按发送） |
| 回复操作 | 复制在局域网 IP（非 https）下也能用；点赞 / 点踩存到服务器（再点取消，点踩可写原因），主管 / 管理员在「AI 用量」里看「没帮助的回复」 |
| 运行信息 | 每轮系统提示写进当前北京时间（到分钟、星期）和这一轮实际用的模型（分组取网关里第一个可用成员，并说明出错时切到谁）；问「现在几点」「你是什么模型」如实回答，不冒充其他模型 |
| 审批预判 | 编辑 / 新建报价时，合计下面提示「提交后要主管审批：原因」或「会自动通过」，规则和后端一致（毛利底线、按目录价算的折扣权限） |
| 代垫费用 | 额外费用可选「代垫费用」（替客户垫付的差旅、第三方采购）：成本 = 单价，按原价收不打折，不计提成，不算进毛利率和折扣权限；报价不能只有代垫费用；打印的报价单上标注「代垫」 |
| 闲聊 | 不再给模型一句固定的自我介绍当参考回复，直接回答这句话；没接模型时问时间、问模型也给真实答案 |

## 问题与修正（本阶段 AI 自己的错误）
| 问题 | 怎么发现的 | 修正 |
|---|---|---|
| 建议「报销和主线无关，可以砍掉」 | 用户指出报销是公司该报的跟单成本 | 保留并照常审批，反而把报销接到商机利润上 |
| 第一次说「个人用时报销不走审批」 | 用户再次指出 | 改回照常审批 |
| 通知里商机链接写成 `?opportunity=`，看板读的是 `?opp=`，点通知只停在看板 | 用户反馈「点任务通知跳到商机」后排查 | 统一成 `?opp=`，任务再带 `task=` 定位；已在看板页时也能响应地址变化 |
| 编辑报价时新加的目录物料用的是文件里的默认价，没用管理员在网页上改过的价格 | 做「改单价」时读代码发现 | 读目录时带上行业包的覆盖配置 |
| 刷新后直接打开 `/ai` 偶尔回不到上次对话：账号信息比页面晚到，恢复被跳过 | 浏览器测试连跑几次有时失败 | 账号信息到了再恢复；账号晚到时不覆盖用户已选的模式 |
| 点赞 / 点踩只弹一句「感谢反馈」，什么都没存；复制直接调 `navigator.clipboard`，用局域网 IP 打开时它不存在，同步报错，按钮没反应 | 用户反馈「复制、点赞、点踩没有任何作用」 | 反馈存表 `ai_feedback`；复制统一走 `lib/clipboard.ts`（不支持时退回旧办法），日报、PRD、账号临时密码的复制也一起改 |
| 系统提示里没有当前时间（只有查数据那条路写了日期）、没有模型信息；闲聊时把固定的自我介绍当「参考回复」交给模型 | 用户问「现在几点 / 你是什么模型会怎么回答」后读链路代码发现 | 新增 `app/agent/runtime.py` 生成运行信息，三处系统提示都带上；闲聊单独组织消息 |
| 单价可改之后，提交审批的折扣按改后的单价算：把单价压低、折扣填 0 就绕过了折扣权限 | 自审「改单价」和审批规则的衔接 | 折扣改按产品目录价比（目录外费用按自己的单价），加回归测试 |
| 点赞点踩按「第几条 AI 回复」编号：重新生成、出错的那轮在历史里和界面上条数不一样，刷新后评价会挂到别的回复上 | 自审对照 `history._merge_turns` 和前端「重新生成」 | 改按「服务端第几条用户消息」编号（`lib/agent-feedback.ts`），加单元测试 |
| 商机侧栏跟进记录还没加载完就点「出方案」，会告诉 AI「还没有跟进记录」 | 自审 | 加载中按钮转圈不可点；读取失败时不写这部分 |
| 日报暂存回来时不看服务器版本：别的设备已保存的新内容会被这台电脑的旧暂存盖掉 | 自审 | 暂存时记下当时的服务器版本，版本变了就丢弃暂存 |
| 导出 CSV 没处理以 = + @ 开头的文字，Excel 打开会当公式执行（CSV 注入） | 自审老模块（导出） | 这类单元格前加 ' 当文本，负数金额不受影响 |

## 测试
- core：报销汇总（草稿不算）、这单赚多少（成交前 / 成交后）。
- web：导航合并入口、模式切换保留各自对话、从工作台按钮进入不新建、刷新恢复、只有新对话才清空、后台生成切回可见。浏览器测试全部用模拟接口。
