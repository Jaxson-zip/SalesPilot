# 个人模式、报价分享链接、新手引导、语音输入

- 日期：2026-10-31 ｜ 工具：Claude Code（单 agent）｜ 模块：core / web

## 任务目标
用户看完「完善程度与易用程度」评估后要求把缺项补上，并说明真实用法：
「我自己用的话主要是出方案给甲方然后直接开发」。一个人接单时，团队版的角色（销售提交、主管审批、管理员配置）是负担。
和用户确认的做法：

| 问题 | 选择 |
|---|---|
| 一个人用时角色太重 | 业务规则里的「个人模式」开关：审批规则触发时自动通过（原因照常记录），主管账号可以进系统配置，隐藏团队相关页面 |
| 方案怎么交给甲方 | 生成可分享的只读报价链接（有效期、可撤销、甲方打开时提醒） |
| 语音输入 | 浏览器自带识别（不支持的浏览器不显示话筒按钮） |
| 新手引导 | 工作台上的上手清单 + 关键页面的首次提示 |

不做（和用户说明过）：上线部署需要服务器；外部情报真实数据源需要付费接口；多公司隔离一个人用不需要。

## 第 1 步：个人模式
- `rules.yaml` 新增 `org.solo_mode`（默认关），业务规则页「工作方式」分组里开关。
- 报价、报销触发审批规则时：个人模式下直接「已审批」，动态写「个人模式免审批（提醒：毛利 10.0% 低于底线…）」，风险不丢。
- `app/common/permissions.can_configure`：管理员，或个人模式下的主管。行业包、业务规则、模型接入、定时任务、战卡、消息推送这 6 处原来各自写 `role == ADMIN`，统一改为它；成员与团队仍只有管理员。
- `/api/me` 返回 `solo_mode`；前端导航换成「工作区 + 设置」，去掉审批、业绩目标、日报、成员与团队；工作台不显示「待我审批」，不叫「团队」；左下角角色显示「个人模式」。
- 测试：`test_solo_mode_api.py`（默认团队模式、主管能配置但不能管成员、销售仍不能配置、低毛利报价免审批且动态记原因、超标报销免审批且仍标超标）；`nav.test.ts`、`permissions.test.ts` 补个人模式用例。

| AI 写错 / 遗漏 | 发现方式 | 修正 |
|---|---|---|
| 测试里定时任务接口写成 `/api/jobs`（实际 `/api/admin/jobs`） | 测试 40401 | 改路径 |
| `/api/me` 加字段后，登录接口的字段集合断言没同步 | 全量测试 3 条失败 | 断言加 `solo_mode` |
| 工作台隐藏审批卡第一版用 `key` 标记再解构丢弃，lint 报未使用变量 | `pnpm lint` | 改成按条件展开数组 |

## 第 2 步：报价分享链接
- 新表 `quote_shares`（迁移 0025）：token（`secrets.token_urlsafe`）、过期时间、撤销时间、打开次数。
- `POST/GET/DELETE /api/quotes/{id}/share`（负责人）+ 公开 `GET /api/public/quotes/{token}`。已审批的报价生成链接时同时走「发送」，前端先确认（规则 19）。
- 公开视图逐字段挑出单价、小计，不用 `model_dump` 透传，成本字段不会因为以后改 schema 漏给甲方；测试里扫整段响应，确保没有 `unit_cost / total_cost / margin / commission`。
- 链接有效期跟报价有效期（`quote.valid_days`）走，不另设阈值；失效、撤销、不存在统一 40401，不让人猜。
- 客户每天第一次打开写动态并通知负责人；带有效 token 的内部预览不计数（`get_optional_user`）。
- 前端：`/share/q/[token]` 放在 `(main)` 外，`SessionProvider` 用 `isPublicPath` 放行；手机优先的卡片布局，可打印 / 存 PDF。报价详情页头「分享给客户」只给负责人、只在审批通过后显示（规则 18）。

| AI 写错 / 遗漏 | 发现方式 | 修正 |
|---|---|---|
| 第一版公开接口不区分访问者，负责人自己点「预览」也会收到「客户正在看报价」的通知 | 自查使用流程 | 加 `get_optional_user`，登录着的内部预览不计数；补测试 |
| 第一版公开视图的项目范围没判断需求清单是否「已确认」、是否同一行业包，和打印版不一致 | 对照打印页 `ProjectScope` | `_scope` 加 confirmed / pack 判断 |
| 测试辅助函数第一版写成了无效代码（`TestClient_ := None or _client`） | 自查时发现，未运行 | 重写为 `_approved(client, tracker)` |
| 测试清理没删分享记录和「客户在看报价」通知，会留在测试库 | 自查 Tracker.purge | `_purge_quotes` 先删 `QuoteShare` 和对应通知 |

## 第 3 步：新手引导
- `GET /api/onboarding`：6 步按角色给，「做没做完」全部按库里的真实数据判断（AI 调用记录、参数改动、客户、跟进、AI 报价、分享链接），不靠前端记。
- 工作台顶部「开始使用」清单：进度条、下一步高亮，做完自动消失，可收起；AI 工作台 / 商机看板 / 报价单列表各一条首次提示；「使用说明」页「重新显示新手引导」。
- 收起状态用 `useDismissed`（挂载前返回 null，避免服务端渲染和首屏闪一下）。

| AI 写错 / 遗漏 | 发现方式 | 修正 |
|---|---|---|
| 新表 `quote_shares` 没登记到 `seed --reset` 的清空列表 | 全量测试 `test_every_table_is_reset_or_kept` 失败 | 加进 `RESET_TABLES` |
| 第一版收起后没有办法再打开引导 | 自查 | 「使用说明」页加「重新显示新手引导」 |

## 第 4 步：语音输入
- 用浏览器自带的 Web Speech API（`lib/speech.ts` 纯函数 + `useSpeechInput` + `VoiceButton`），不经过 core，也不花模型费用。
- 接在 AI 对话框、客户页记跟进、「粘贴纪要」弹窗：开始时记下已有内容，边说边把识别结果（含临时结果）接在后面，缺结尾标点补逗号。
- 浏览器没有 `SpeechRecognition` 时不渲染按钮（规则 18）；国内 Chrome 的 `network` 错误提示换 Edge 或用输入法语音。
- 只写了纯函数的单元测试；真机说话的效果需要在 Edge 里手动试（自动化测试里没有麦克风）。

## 第 5 步：容器里验证
- `docker compose build core web` 后启动（迁移 0025 随 core 启动执行）。
- 浏览器（张晨）：工作台「开始使用 3/4」，下一步高亮「把报价链接发给客户」；Q-2026-003 详情页「分享给客户」→ 生成链接；手机宽度打开 `/share/q/…` 显示明细、合计、大写、条款；不带登录请求公开接口，响应里没有 `unit_cost / total_cost / margin / commission`，张晨收到「南山教育集团正在看报价 Q-2026-003」；乱写的 token 显示「链接已失效」；AI 对话框出现「语音」按钮。
- 没在浏览器里验：个人模式开关（改的是全局配置，API 测试已覆盖）、真机说话识别（需要麦克风）。

| AI 写错 / 遗漏 | 发现方式 | 修正 |
|---|---|---|
| 分享弹窗的有效期用 `expires_at.slice(0, 10)`：后端按 UTC 返回，北京时间 0 点会显示成前一天，只是碰巧对 | 浏览器里看到后对照时区 | 改用报价自己的 `valid_until`（日期，不带时区） |
