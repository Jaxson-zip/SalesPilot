# 学习问答检索全部行业包

- 日期：2026-10-31 · 开发者：Claude Code · 模块：core / agent

## 任务卡
- **背景**：检查「知识库没有的东西 AI 会不会讲」时发现，学习问答问「客户开发到一半要加功能，怎么收费？」只在「大模型部署」资料里检索，答不出来。《需求变更与验收》明明在软件外包知识库里。
- **原因**：检索范围按 商机产品线 → 团队默认产品线 → `DEFAULT_PACK` 决定。演示团队「华南销售组」的默认产品线是大模型私有化部署，问题里又没点名「外包」，于是只查了 company + pack:llm_deploy。
- **目标**：学习问答（新人了解全部产品线、不绑定商机）检索公司制度和全部行业包；用户点名某个行业包时仍只查那个；做方案模式不变。
- **范围**：`policy_tools.py`、`tools/base.py`（INJECTED_ARGS）、`nodes/tool_loop.py`、`nodes/crm.py`（无模型时的规则兜底）、`prompts/learn.md`。

## 做了什么
1. `SearchPolicyArgs` 新增系统注入字段 `all_packs`，并加进 `INJECTED_ARGS`。模型看不到这个字段，也改不了；由会话模式决定，learn 时为 true。
2. `_scope` 改为返回 (pack, scopes, 范围说明)，优先级是：点名的行业包 > 学习问答查全部 > 当前会话行业包。
3. learn.md 加了两条：先调工具、拿到结果再下结论，不在查资料前给「通常是…」的经验判断；引用行业资料时说明是哪个行业。
4. 回归测试 3 个：学习问答查全部行业包、点名时只查那个、做方案模式只查当前行业包。同时断言 `all_packs` 不出现在给模型的 schema 里。

## 校验与兜底
- AI 第一版回答「下面只能给你能确定的部分」，然后把公司合同审批、提成规则拼成了答案。资料是真的，但答非所问。这是检索范围问题，不是模型编造。
- 修改前的另一个现象：回答开头在调用工具前先给了一句经验结论，又重复了一次「先说结论」，已通过提示词约束。
- 做方案模式不改：报价和行业包绑定，跨行业检索会把别的行业的参考资料混进方案里。

## 验证
- core 全量测试 679 passed，ruff 通过。
- 重建 core 后实测：「中途加功能怎么收费」命中《需求变更与验收》《合同风险条款》，回答都标了出处；「年假几天」仍回答「知识库里没有找到」。
