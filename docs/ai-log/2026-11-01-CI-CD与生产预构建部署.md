# 任务卡：CI/CD 自动化流水线与外部预构建部署优化

## 1. 任务背景与目标
- **背景**：生产 VPS 云主机存在较高的 CPU 争抢（CPU Steal ~79%），导致在低配 VPS 上直接执行 Next.js 全量编译耗时接近 40 分钟甚至引发进程超时与卡死。但在运行阶段，容器实际内存消耗仅约 500MB，CPU 占用极低。
- **目标**：
  1. 将编译构建与生产运行解耦：停止在 VPS 上现编 Next.js 前端；
  2. 建立 GitHub Actions 自动化构建与发布流水线（.github/workflows/deploy.yml），自动构建多镜像推送到 GitHub Container Registry (ghcr.io)；
  3. 支持本地/外部预构建后直接传输镜像或拉取预构建镜像，VPS 仅需 `docker load` / `docker compose up -d`，更新时间由 40 分钟压缩至 15~20 秒，实现轻量稳定运行。

## 2. 变更内容
- **GitHub Actions 流水线**：
  - 新增 `.github/workflows/deploy.yml`，监听 `main` 分支 push，自动运行测试、并行构建 `salespilot-web`、`salespilot-core`、`salespilot-gateway` 并推送到 GHCR。
- **生产 Compose 配置支持外部镜像**：
  - `docker-compose.prod.yml` 引入环境变量 `${WEB_IMAGE:-salespilot-web:latest}`，既兼容本地离线导入的 `salespilot-web:latest`，也无缝支持 GHCR 预编译镜像。
- **一键更新脚本**：
  - 新增 `infra/update-prod.sh`，仅需拉取代码并重启容器，执行数据库迁移，15 秒完成上线。
- **业务功能补全**：
  - 行业包报价条款自动联动回款方案（`pack_quote_terms`）。
  - 前端打印报价页面支持显示行业包条款。
  - 客户画像与 AI 对话工作台交互体验优化。
