# 三个角色逐页、逐弹窗检查，修正误导提示并拆分超长文件

- 日期：2026-11-02 · 开发者：Claude Code · 模块：web（权限提示、报价调价、商机抽屉、日报）、core（日报、出方案节点）
- 上一份：`2026-11-02-手机端AI工作台右侧被裁.md`

## 任务卡
- **背景**：用户要求整体检查项目缺陷，并用不同权限的账号逐个打开页面和弹窗。超长文件有必要拆的就拆，重点是功能。
- **做法**：
  - 在本地 Docker 上分别用销售（张晨）、主管（李薇）、管理员（周敏）三个演示账号登录，宽度 360。
  - 逐页打开，把页面上能打开弹窗、抽屉、下拉菜单的按钮逐个点开，检查三件事：
    - 有没有内容超出屏幕；
    - 有没有接口报错（HTTP 非 2xx 或 code≠0）；
    - 有没有「看得见点不了」的按钮。
  - 只打开、不确认：报价「提交」没有确认框，「复制为新版本」会直接建数据，这两个没点；企业微信「发送测试消息」、定时任务「立即运行」会推送到真实的群，也没点。

## 检查范围
- **销售**：
  - 客户列表：批量导入、新建客户、视图 / 筛选 / 排序 / 选项菜单；
  - 客户详情：退回公海、添加下一步、粘贴纪要，以及四个标签页；
  - 商机：新建、商机抽屉、标记为输单；
  - 报价：草稿、已审批、已发送、客户拒绝、已接受各一张，打开审批规则、提成规则、添加物料、分享给客户、撤回修改、发送客户、客户接受、客户拒绝；
  - 合同抽屉、新建报销，草稿 / 待审批 / 已驳回报销抽屉；
  - AI 工作台：会话记录、行业包、模型选择；
  - 手工新建报价。
- **主管**：按人交接、登记回款、合同抽屉、审批的驳回 / 通过 / 排序、业绩目标设置、团队日报、团队视图切换。
- **管理员**：
  - 成员：新建团队、改团队、新建成员、编辑、重置密码、停用；
  - 业务规则：编辑、恢复默认；
  - 行业包：产品目录、业务规则、知识库；
  - 模型：编辑、添加厂商；
  - 竞品战卡：新建、编辑、删除；
  - 推送设置、定时任务、操作日志、AI 用量这几页只看了页面本身。

## 发现的问题与处理
| # | 问题 | 处理 |
|---|---|---|
| 1 | 没有权限的页面提示「可在左下角切换角色」。线上是正式模式（DEMO_LOGIN=false），左下角只有修改密码和退出登录，没有切换入口，提示会误导用户 | 各页面的提示里去掉这句。`RoleGate` 读 `/api/auth/options`，只在演示环境追加「可在左下角切换演示账户查看」 |
| 2 | 超出 400 行上限的文件（规则 13） | 按功能拆分，行为不变：<br>· `report_service.py` 421 → 360：日报的入参出参挪到 `schemas/report.py`，本来就该放在 schemas 层；<br>· `nodes/solution.py` 404 → 357：需求清单读写挪到 `nodes/requirement_store.py`；<br>· `QuoteAdjust.tsx` 464 → 308 + `QuoteAdjustParts.tsx`；<br>· `OpportunitySheet.tsx` 462 → 272 + `OpportunitySheetParts.tsx`；<br>· `reports/page.tsx` 426 → 245 + `components/reports/ReportParts.tsx` |
| 3 | `prepare_chat` 超过 50 行（上一轮行业包修复又加了几行） | 关联商机和行业包的逻辑抽成 `_apply_link_and_pack`，现在 48 行 |

- 其余页面和弹窗在 360 宽下都没有内容超出、没有接口报错。
- 置灰的按钮只有表单没填完时的提交按钮（例如输单没选原因时的「确认输单」），属于表单校验，不是「无权限却显示」。

## 没有拆的
- `types/biz.ts`（576 行）只有类型声明。`components/ui/sidebar.tsx` 是 shadcn 生成的组件。
- 还有 11 个函数略超 50 行，例如：
  - `customer_import.import_customers`（73 行）；
  - `target_service.board`（75 行）；
  - `report_service.collect_facts`（72 行）；
  - `prd_generator.skeleton`（72 行，主要是模板文字）。

  这些函数逻辑连续，拆开不会更好读，也不影响功能，这次不拆。

## 校验与兜底
- **检查脚本的误报**：在 iframe 里量抽屉时，内层标题栏显示「超出到 385px」。换成真实的 360 视口截图核对，新建客户、会话记录抽屉都完整显示，所以这是 iframe 测量的误报，不是页面问题。
- **拆分脚本漏了一个 import**：判断某个导入是否还在用时，没把 `...REDRAFT_REPORT_CONFIRM` 这种展开写法算作使用，把它删了。typecheck 报错后补回。
- Git Bash 会把 `@/components/...` 参数改写成 Windows 路径，导致 import 写错，已修正。
- OpenAPI 里日报 `RemindIn` 的组件名随模块路径变了（内容不变），已重新导出 OpenAPI 和前端类型。
