# 输单商机在看板上看不到，商机侧栏仍引导跟进和报价

- 日期：2026-11-02 · 开发者：Claude Code · 模块：web（商机看板、手机端阶段列表、商机侧栏、手工报价）
- 上一份：`2026-11-02-输单后状态过期与表单未保存保护.md`

## 任务卡
- **背景**：外部复测：
  1. 「商机 → 筛选 → 阶段 → 输单」显示 4 条，看板各列却都是空的。默认页显示共 7 条，只看到 3 张卡片。
  2. 「IT 设备换新」已输单，侧栏写着「已输单，不能再切换」，下面仍提示安排下一次跟进；「手动报价」能打开，还自动关联这个输单商机。
- **做法**：对照代码找原因，修复后补回归测试，在本地浏览器核对。

## 原因
- **看板**：只有线索、需求确认、方案报价、商务谈判、赢单五列，输单只是拖拽时出现的「拖到这里标记为输单」区域，本身不占列。列表接口返回了输单商机，筛选栏也把它们算进条数，但页面上没有任何地方显示。手机端的阶段标签也只有这五个。
- **侧栏**：
  - 「手动报价」「出方案」只看是不是本人负责，没看商机是否已结束。
  - 下一步任务区在没有待办时固定提示「建议约好下一次跟进」。输单时待办已经自动完成，所以这条提示一定会出现。
  - 手工报价页按地址里的 `?opp=` 直接关联商机，不看阶段。后端出报价时会拦下（`ensure_deal_open`），但这样就成了「看得见、点了才报错」。

## 修改
- **看板**：五列下面加「输单」一栏，显示条数和金额，可展开、收起。卡片只读，点开看详情。只剩输单商机时（例如按输单筛选）自动展开。
- **手机端**：阶段标签加上「输单」（`LIST_STAGES`）。
- **侧栏**：
  - 赢单或输单后，不显示「手动报价」「出方案」；「粘贴纪要」保留，复盘时还要用。
  - 输单后不显示下一步任务区。
- **手工报价页**：从输单商机进来时只带客户，不自动关联商机；关联商机的下拉选项里也去掉了输单商机。

## 没有改的
- AI 工作台的示例问题「把星河设计的商机推进到商务谈判」是固定文字。演示数据里这个商机处于「需求确认」，复测时被手动输单了，所以示例跟当前数据不一致。这时让 AI 推进，后端会提示已输单、不能切换。恢复演示数据（`seed --reset`）后示例就有效了，所以这次没有改示例。
