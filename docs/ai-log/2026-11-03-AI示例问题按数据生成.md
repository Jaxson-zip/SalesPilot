# AI 工作台示例问题按当前数据生成

- 日期：2026-11-03 · 开发者：Claude Code · 模块：core（模板接口）、web（AI 工作台示例卡片）
- 上一份：`2026-11-02-输单商机看不到与仍引导报价.md`

## 任务卡
- **背景**：AI 工作台的示例「把星河设计的商机推进到商务谈判」是写死的。商机删了或者输单了，它还在推荐。用户确认改成按数据生成。
- **做法**：
  - 示例仍然在 `rules/templates.yaml` 里配置，改成可以带占位符，由后端按本人负责的数据填写。
  - 缺数据时用 `fallback`；没有 `fallback` 的就不显示这张卡片。

## 修改
- 新增 `app/crm/services/prompt_fill.py`：
  - `{customer}` `{contact}`：本人最近更新的、有联系人的客户和它的一位联系人；
  - `{opp_customer}` `{opp_name}` `{next_stage}`：本人最近更新的进行中商机（线索～方案报价）和它的下一阶段。商务谈判的下一步是赢单，属于不可逆操作，不拿来当示例。
- 销售的示例：
  - 「对话报销」「记跟进」换成上面的客户和联系人，没有就用不带客户名的通用写法；
  - 「推进商机」用本人的进行中商机，没有就不显示。
- `get_templates` 改为接收数据库会话和当前用户；接口路径和返回结构不变，OpenAPI 没有变化。
- 前端模板缓存 10 分钟。AI 工作台的示例卡片改成每次打开都重新取（`useTemplates({ fresh: true })`），商机输单或删除后再打开就会换掉。

## 没有改的
- 「出方案报价」用的是各行业包自己的例句，比如大模型部署用明理律所、软件外包用晨光烘焙、办公设备用星河设计。这些是「客户提了什么需求」的场景描述，客户要和行业对得上。换成最近的客户，会出现律所做蛋糕小程序这种不合理的组合，所以保持不变。
- 主管和管理员的示例本来就不带具体客户，不用改。

## 校验与兜底
- 本地数据里最近更新的是之前测试留下的客户（「E2E脱敏客户」「QA超大预算」），示例就显示了它们。这符合预期：示例会反映当前数据。录演示前跑 `seed --reset`，示例就会回到演示客户。

## 验证
- 新增测试：
  - `tests/unit/test_prompt_fill.py`：有数据时填写、缺数据时用 fallback 或隐藏；
  - `test_templates_api.py::test_advance_prompt_follows_own_open_deal`：新建商机后，「推进商机」指向它；输单后不再出现。
