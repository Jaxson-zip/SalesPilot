# 待办加入回款逾期、日报和待审批

- 日期：2026-11-03 · 开发者：Claude Code · 模块：core（工作台）、web（工作台待办卡片）
- 上一份：`2026-11-03-AI示例问题按数据生成.md`

## 任务卡
- **背景**：用户反馈两点：逾期的事项不在待办里；日报也不在待办里。
- **做法**：先查清待办的数据来源，再把应该当天处理的事项都放进待办。

## 原因
- 工作台待办只读任务表，显示今天到期和已逾期的任务。逾期任务本来就会显示。
- 回款逾期、回款今天到期、日报催交是定时任务发的站内通知，只出现在右上角铃铛里，待办里没有。用户看到的「逾期事项」是回款逾期。

## 修改
- 新增 `app/crm/services/todo_service.py`，按当前数据实时计算，不读通知。处理完（登记回款、提交日报、审批完）就自动消失：
  - 回款：有效合同里已逾期、或今天到期还没收齐的期次。数据范围和合同页一致，用的是同一套「回款按期次顺序冲抵」的计算（`plan_states`）。
  - 日报：销售本人在工作日还没提交当天日报时显示，草稿不算提交。口径和日报催交定时任务一致：只针对销售，只在工作日。
  - 待审批：主管显示「处理待审批（N 条）」。口径和工作台「待审批」卡片一致：固定按本团队统计，不随视图切换。
- 新接口 `GET /api/dashboard/todos?view=`，router 只做参数和响应。
- 前端 `TodoCard`：
  - 上面是这三类事项，下面是任务。这三类事项没有勾选框，点标题跳到合同回款计划、日报页或审批页处理。
  - 标题旁的条数、「逾期 N」、工作台问候语里的「今天 N 项待办，M 项已逾期」都把它们算进去。
- 新数据用的查询键放在 `["dashboard", ...]` 下面。登记回款、冲正、审批原本就会刷新这一组缓存，新数据会跟着刷新。另外在提交日报时补了一次刷新。

## 没有改的
- 商机停滞和报价快过期仍然只发通知。它们是「该跟进了」的提醒，不是有明确截止时间的事项，放进待办会让待办常年很长。
- 用户问的「删了商机报价单没同步删」：系统里没有删除商机的入口，只能输单或赢单。从 `432a019` 起，输单会关闭该商机上还在进行中的报价，这次没有改动。

## 校验与兜底
- 合同的回款期次第一版是在循环里逐份调用 `plan_states`，自查时发现会变成每份合同各查一次库，改成一次查出全部合同的期次。
