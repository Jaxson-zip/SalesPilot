# 上传与导入的异常输入：DOCX / CSV 返回 500

- 日期：2026-11-05 · 开发者：Claude Code · 模块：agent/materials、agent/samples、crm 客户导入、知识库上传、common/response
- 上一份：`2026-11-05-第二份试用报告核实.md`
- 起因：试用反馈异常 DOCX 上传返回 HTTP 500；CSV 导入时超长数字触发 500，超出上限的预算没在预览阶段被拦下；另请排查其他小问题。

## 怎么查的
对本地 nginx（:8080，与线上同一套配置）用脚本发构造的异常文件和异常参数，记录每种情况的 HTTP 状态和错误码。覆盖范围：
- 材料上传 12 种文件；
- 客户导入：CSV 11 种、xlsx 3 种；
- 8 个列表接口的分页、搜索、排序参数，6 种详情路径的异常 id；
- 客户、商机、跟进、报销写接口的超长、控制字符、超大金额。

## 发现与处理
| 问题 | 原因 | 处理 |
|---|---|---|
| 不支持的压缩方式、带加密标记的 .docx → 500 | `zipfile` 抛 `NotImplementedError` / `RuntimeError`，只捕获了 `BadZipFile` 等三种 | 捕获 zip 和 XML 解析可能抛的所有异常，统一返回 40001「Word 文件无法读取（可能已损坏或加密）」 |
| 10 MB 的 .docx 能解压出 300 MB 正文，全部读进内存后才报错（压缩炸弹） | 先读后判断 | 先看压缩包头里的解压大小，超过 30 MB 直接拒绝；正文里有 DTD / 实体声明也拒绝（正常 .docx 没有，防实体膨胀） |
| 扩展名是 .png / .jpg 但内容不是图片 → 照样送给视觉模型，返回 502「识别失败」 | 只按扩展名判断 | 先核对文件头（png / jpg / webp），不是图片直接 40001，不调模型；样例图片分析同样处理 |
| CSV 预算列写一长串数字 → 500 | 用 `float` 计算，溢出成 inf，`round` 报错 | 改用 `Decimal` 计算 |
| 预算超过 100 亿元（10²⁰、2 百亿、99999999 万）预览显示「可导入」 | 导入没有用全系统统一的金额上限 `MAX_AMOUNT_FEN`；确认导入时超出 BIGINT 会 500，没超出的就写入了不合理的金额 | 预览阶段按同一上限报错「年度预算不能超过 100 亿元，请检查是否多填了几个 0」，这一行不导入 |
| CSV 某个格子超过 128 KB → 500 | `csv` 模块抛 `csv.Error` 没有捕获 | 返回 40001「CSV 格式有误：某个格子内容过长或引号不配对」 |
| CSV 里带 NUL 控制字符：预览显示可导入，确认时 500 | PostgreSQL 文本字段不能存 NUL | 预览阶段报错，这一行不导入 |
| 损坏的 .xlsx 解析到一半出错可能 500 | openpyxl 在打开和逐行读取时都可能抛各种异常，只捕获了打开阶段的三种 | 读取全程统一按文件不合法处理 |
| 知识库上传损坏的 PDF / Excel → 502，并把原始异常文字显示给页面 | 解析失败和向量模型故障混在一起处理 | 解析失败返回 40001「文档无法读取」；向量模型故障仍返回 502，原始异常只写日志 |
| **其他接口**：客户、商机的名称和客户、商机、报价的搜索词带 NUL 字符 → 500（共 6 处） | 同上，数据库拒收 | 全局处理 `sqlalchemy.exc.DataError`：带 NUL 时返回 40001「内容里有不可见的控制字符」，其余（数值超出范围、格式不对）返回「数据格式不对或数值超出范围」。以后新接口遇到同类输入也不会再出 500 |

其余边界输入都已正确返回 4xx：负数页码、超大 page_size、非法排序字段、非法 uuid、超大金额、错误日期、非法 JSON、20 MB 请求体等。

## AI 写错、人工修正
| 问题 | 原因 | 修正 |
|---|---|---|
| 最初写 `docx_text` 时只捕获了三种异常 | 只想到「不是 zip」「没有 document.xml」「XML 坏了」，没考虑加密和压缩方式 | 列出 zipfile 可能抛的全部异常 |
| 导入金额没有复用 `MAX_AMOUNT_FEN` | 导入是单独写的解析逻辑，没回头对齐表单的校验规则 | 改为同一常量；测试覆盖正好 100 亿和超出的情况 |
| 第一版测试里留了一句 `assert ... or True` | 写到一半想验证另一件事，没删干净 | 删除（这种断言永远成立） |
