## 走查范围（本地，浏览器）
- 张晨（销售）：客户详情 → 写跟进 → 商机 → 手动报价（毛利 22.9%）→ 提交审批；市内打车报销 → 上传发票 → 提交（自动通过）。
- 李薇（主管）：审批中心通过报价、驳回招待报销；合同页登记回款 ¥405,000，提成按 90% 确认。
- 张晨：被驳回的报销显示驳回原因和审批记录；报价发送 → 客户接受 → 自动生成合同和回款计划。
- 周敏（管理员）：成员与团队、业务规则、操作日志。
- 刘洋（华东销售，密码登录）：只看到自己的 2 个客户；手机尺寸下报销表单正常。
- 走查期间临时关掉本地数据库里的企业微信推送开关，避免往真实群里推消息，走查后恢复。

## 发现的问题与修正
| 问题 | 原因 | 修正方式 |
|---|---|---|
| 删除草稿后，工作台「我的动态」还显示「新建了报销单 E-2026-003」 | 删草稿时只删了报销单和票据，没删它的动态 | 新增 `activity_service.remove_for`，删草稿时一并清掉；回归测试 |
| 操作日志里审批只写「审批 · 成功」，看不出批的是哪张单、通过还是驳回 | 审批对象不在日志的名称查找表里，也没有补说明 | 审批时用 `audit_service.note` 写「通过报价单 Q-… / 驳回报销 E-…：原因」；回归测试 |
| 操作日志里「删除报销草稿」没有单号 | 删除后按 id 查不到名称 | 删除前记下「单号 · 金额」；回归测试 |
| 华东组销售登录后「我的动态」是空的 | 演示数据只给张晨写了动态，`seed_activities` 的负责人写死为张晨 | 给青禾、恒远补跟进和阶段变化动态，负责人按行指定；回归测试 |
| 悦海合同的「预付款」到期日（11-02）比「到货验收款」（10-31）还晚 | 演示逾期时只把第 2 期改到 5 天前 | 前面各期按每期 30 天往前推；回归测试 |
| 驳回报销时，示例写的是「维保改为 1 年后重新提交」 | 示例文字是按报价写的，报销共用 | 按单据类型给不同示例 |
| 地址写错时是 Next.js 默认英文白页，没有返回入口 | 没有 `not-found` 页 | 新增中文 404 页，带「回到工作台」 |
