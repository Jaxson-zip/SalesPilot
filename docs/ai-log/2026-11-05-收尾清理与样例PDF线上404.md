## 清理时发现的 bug：样例 PDF 线上 404
- 现象：报销「上传须知」里的样例发票 PDF、知识库「样例文档」PDF，线上 `https://crm.jaxson.bond/samples/*.pdf` 都返回 404。
- 根因：`.gitignore` 里为课程材料写了 `*.pdf`，`apps/web/public/samples/` 下的两份 PDF 被一起忽略。本地有文件（由 `scripts/samples/build.mjs` 生成），所以本地一直正常；仓库里没有，CD 从仓库构建的线上镜像里就没有。之前知识库的演示 PDF 也是这样漏的，当时只给 `seed/knowledge` 加了例外，没有排查别处。
- 修复：`.gitignore` 增加 `!apps/web/public/samples/*.pdf`，提交两份 PDF。提交前确认过内容：样例发票是虚构的（全零发票号、`XXXX` 税号、「样例 · 非真实发票」水印）；`kb-sample.pdf` 与仓库里的 `合同审批与回款流程.pdf` 逐字节相同。
- 回归测试 `apps/web/lib/__tests__/public-samples.test.ts`：扫描 `app/`、`components/`、`lib/` 里所有 `/samples/*` 引用，要求文件存在，且没有被 git 忽略（用 `git check-ignore` 判断）。改 `.gitignore` 之前跑，两份 PDF 失败、其余 5 个通过；改之后 7 个全部通过。
