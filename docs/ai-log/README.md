# AI Coding 记录目录

SalesPilot 从选题到交付全程用 Claude Code 开发。每个阶段一篇记录，写明任务目标、AI 做了什么、**AI 哪里写错了、是怎么发现和修正的**，以及测试结果。

## 典型问题：AI 写错了什么，怎么发现的

从各篇「问题与修正」表里挑出最有代表性的十条。发现手段比修正本身更值得看：大多数问题单元测试全绿，是靠浏览器实测、截图、对照文档、在旧版本上回跑测试才发现的。

| # | AI 写错了什么 | 怎么发现的 | 怎么改的 | 出处 |
|---|---|---|---|---|
| 1 | 三个子 agent 并行开发，后端推送的方案字段（`total_price`、`margin_rate`）和前端假设的（`price`、`margin`）对不上，卡片退化成原始 JSON | 联调时浏览器里看到 JSON | 以接口契约为准统一字段；后来加上 OpenAPI 生成类型 + `contract-check.ts`，前后端不一致直接编译失败 | [骨架搭建](2026-10-25-项目骨架搭建.md) |
| 2 | 工作台动态显示 `create`、`attachment_added` 等英文代码，**单元测试却全绿**：前端猜了动作代码格式，测试数据也是按猜测写的 | 浏览器实测 | 按后端实际值改；新增测试：契约里每个动作代码都必须有中文 | [业务模块](2026-10-26-业务模块.md) |
| 3 | 权限只做了「能看什么」，没做「能改什么」，管理员能直接改销售的商机 | 工作台动态里出现「管理员更新了商机阶段」 | 后端集中实现 `ensure_owner` 等校验，所有写操作复用 | [权限与可用性](2026-10-26-权限与界面可用性.md) |
| 4 | 架构里写「回答必带出处」，前端有来源组件，但后端从来没推送过来源 | 写知识库说明时逐句核对 | 检索命中时推送并保存来源 | [RAG 与交付文档](2026-10-27-RAG多格式与交付文档.md) |
| 5 | 欢迎页的示例问题「承诺」了做不到的事（问提成、问未跟进客户），没有对应工具，模型只能编 | 盘点工具清单时对照示例问题 | 示例问题改为从模板按角色读取，只放有工具支撑的 | [function calling](2026-10-27-function-calling与业务模板.md) |
| 6 | 日报草稿编出当天没做过的拜访 | 接真实模型实测 | 事实只从操作日志、跟进、任务取，模型只负责组织语言 | [销售增强](2026-10-28-销售增强功能.md) |
| 7 | 第一次 AI 评估里「大模型」那一列大部分其实是规则兜底的结果 | 看网关日志，从第 6 条起全部报错 | 评估脚本自己调模型，失败单独记「模型调用失败」，不混进成功率 | [软件外包行业包](2026-10-28-软件外包行业包与评估.md) |
| 8 | 改提示词修好一条用例，另一条开始固定失败 | 全量重跑评估 | 补充提示词约束；定下规矩：改提示词必须全量重跑评估（已做成提交钩子） | [软件外包行业包](2026-10-28-软件外包行业包与评估.md) |
| 9 | 为「方案卡被顶出视口」写的滚动测试，在**未修复的旧版本上也能通过**，等于没测 | 先在旧版本上跑新测试 | 模拟数据补上真实顺序里的物料清单，旧版本失败、新版本通过后才算数 | [审查报告核实](2026-10-29-审查报告核实与修复.md) |
| 10 | 测试会往真实企业微信群发消息；推送在事务回滚后仍会发出 | 写推送功能时自查 + 代码审查 | 测试全局拦截真实发送；推送改为事务提交后才发 | [销售增强](2026-10-28-销售增强功能.md) |

另外几类反复出现、值得记住的：

- **环境问题伪装成代码问题**：容器「健康」但跑的是旧镜像；改了 `.env` 不生效（Compose 只在创建容器时读取）；Git Bash 把 `/tmp` 改写成 Windows 路径。
- **脚本改文件「成功」但没改**：工作区是 CRLF，脚本按 LF 匹配，没匹配上也不报错（出现 3 次）。之后脚本一律先统一换行、找不到就报错。
- **AI 的修正也会被采纳**：文档里的显存公式会把 GQA 模型的 KV Cache 高估约 5 倍，AI 指出后改用「KV 头数 × 每头维度」。

## 协作中固定下来的做法

- 改了 AI 相关代码（agent、行业包、模型调用、评测）提交前自动跑评估，分数低于基线不让提交。
- 修 bug 先写能复现的测试，并确认它在旧版本上失败。
- 浏览器测试不在真实数据上点写操作：用 `page.route` 模拟接口，或测试后清理。
- 密钥只放在不进仓库的 `.env`，测试不调用真实推送。
- 界面改动在 1280 / 1440 / 390 宽下截图核对。
