# 功能说明

README 只讲项目是什么、怎么跑起来；各模块的具体行为、配置项和运维开关写在这里。界面内的「使用说明」页面向最终用户，这里面向部署和维护的人。

## 模块一览

| 模块 | 能做什么 |
|---|---|
| AI 方案工作台 | 对话出方案报价（显存估算 → 配置 → 毛利校验 → 不达标自动重配 → 确认后生成报价单）；对话记跟进、改商机阶段、安排下一步、报销、查制度（带出处）；一次沟通的跟进 + 下一步 + 阶段推进一张卡片确认；每轮带上当前这单的最新状态，「好，按刚才说的出方案」这类短句能接上；主管处理审批；执行过程（思考 → 调用 → 结果）可视化 |
| 客户 / 商机 | 列表筛选排序导出、多选批量操作、主管转移负责人；商机看板拖拽（可撤销）、赢单 / 输单确认；下一步任务、阶段默认赢率、久未跟进提醒；「需要注意」按这单状态列出停滞、下一步逾期、赢单要素缺口、没报价、报价未发、回款逾期，一键交给 AI |
| 报价 / 合同 | 报价调价（规则重算毛利和是否需审批）、正式报价单打印 / 存 PDF（不含成本毛利）；合同、回款计划与登记、开票跟踪（销售申请 → 主管登记，已开票未回款提示）、提成按回款确认；AI 出方案可在三档里另选后生成报价单 |
| 报销 / 审批 | 按类型填写（客户招待选参与人、差旅填行程、住宿按城市每晚标准校验）、模板和报销须知、上传票据自动存草稿、超标自动转主管审批 |
| 软件外包报价 | 可上传客户样例图片（最多 30 张），AI 识别单据类型、字段和清晰度，据此定识别难度并追问字段；模糊需求分三步：AI 拆功能模块并给粗估区间和确认问题 → 需求卡片上增删模块、标二期 → 确认后出三档报价；支持个人全栈，成本拆成人工、AI 编码工具、第三方代采，并估算上线后的 AI 调用费 |
| 销售辅助 | 上传纪要 / 聊天记录 / 名片一键整理成跟进和联系人；MEDDIC 赢单要素与阶段风险；竞品战卡；日报（按当天真实操作生成草稿）；客户外部情报（演示数据） |
| 数据安全与集成 | 操作日志、电话脱敏与查看留痕、导出按角色授权；企业微信群推送（待审批、赢单喜报、日报）；AI 用量与成本统计 |
| 个人模式 | 一个人接单时在「业务规则 → 工作方式」打开：报价、报销触发审批规则时自动通过（原因记在动态里），主管账号可以进入模型接入、行业包、业务规则等系统配置，审批、业绩目标、日报、成员管理等团队页面隐藏 |
| 报价分享链接 | 报价审批通过后，详情页「分享给客户」生成一条免登录的只读链接（复制链接或一段发给客户的话，粘贴到微信）；客户在手机上看到明细、合计、条款和项目范围，看不到成本和毛利；客户每天第一次打开会通知负责人；链接跟报价有效期一起过期，也可以随时撤销 |
| 新手引导 | 工作台顶部的「开始使用」清单：接入模型、调报价参数（能改配置的人才有）、录客户、记跟进、AI 出方案、把报价链接发给客户，做没做完按真实数据打勾，全部完成自动消失；AI 工作台、商机看板、报价单列表第一次打开有一条用法提示，关掉后不再出现，「使用说明」页可重新显示 |
| 语音输入 | AI 对话框、客户页记跟进、「粘贴纪要」里的话筒按钮：点一下开始说，再点停止，文字接在已输入内容后面（浏览器自带识别，不经过服务器、不花模型费用）；浏览器不支持时不显示按钮。国内 Chrome 连不上识别服务时会提示换 Edge 或用输入法的语音输入 |
| 权限 | 销售只改自己的数据；主管看团队、审批、登记回款、按人一键交接客户（离职 / 调岗）；管理员只读并配置行业包；无权按钮不显示 |
| 账号 | 账号密码登录（错 10 次锁 10 分钟）、修改密码；管理员新建成员（临时密码、首次登录强制改密）、改角色和团队、重置密码、停用（立即下线并通知主管交接客户）、新建 / 改名团队；演示环境可一键进入演示账户，公网部署可设访问口令 |
| 列表 | 客户 / 报价 / 合同 / 报销服务端分页（每页 50 条）、多选筛选和排序，筛选项覆盖整个数据范围；导出按当前筛选取全部（受单次条数上限约束） |
| 通知 | 铃铛、工作台待办；每条通知点开直接定位到要处理的记录（审批、报销单、商机任务、回款计划） |

## 模型接入

模型可以写在 `.env` / `services/gateway/models.yaml`，也可以由管理员在「系统设置 → 模型接入」里配置，保存后立即生效：

- 内置厂商（混元、DeepSeek、通义）改 Key、接口地址、协议；
- 添加自定义厂商（Kimi、智谱、自建 vLLM / Ollama 等任意 OpenAI 兼容接口），测试连接时自动检测工具调用等能力；
- 选对话、重排的主用和备用模型；
- 切换知识库向量模型（后台重建全部向量，成功后才切换）。

Key 加密保存（`MODEL_KEYS_SECRET`）、只显示末 4 位。改 `.env` 后需要重启：`docker compose up -d gateway core`。

- 网关模型列表：http://127.0.0.1:8100/v1/models （需要 `Authorization: Bearer <GATEWAY_INTERNAL_KEY>`）
- 新增内置模型只改 `models.yaml`，并跑契约测试：`cd services/gateway && uv run pytest tests/contract -k <别名>`

## 知识库

```bash
docker compose exec core python -m app.rag.ingest --scope all
docker compose exec core python -m app.rag.evaluate          # 评测：Top-4 命中率 / 拒答率
```

core 启动时如果知识库为空且有可用的 Embedding 模型，会自动入库一次。管理员也可以在「行业包配置」里上传文档（Markdown / PDF / Excel），上传时立即向量化，失败则不保留文件。资料来源、切块和检索参数见 [知识库构建说明](知识库构建说明.md)。

## 学习问答（新人带教）

AI 工作台顶部可以切换「做方案 / 学习问答」。学习问答给刚入职的销售了解公司：卖哪些产品、销售阶段怎么走、报价折扣和毛利审批、提成和报销标准、主要竞品怎么应对。它只按知识库、业务规则和竞品战卡回答，每条标出处，查不到会直接说没找到；只读，不查客户、不改数据。

内置的产品目录价格和知识库文档是**示例资料**（「行业包配置」里标「示例资料」，学习问答回答时也会提醒）。正式使用前请在「行业包配置」里改成真实价格、上传公司真实的制度和产品文档，再把对应 `pack.yaml` 的 `sample_data` 改为 `false`；引导问题在 `rules/templates.yaml` 的 `learn_prompts` 里调整。

## 业绩目标

主管按月给本团队每个人设签约额目标（按万元填，可「复制上月目标」），团队目标是成员目标之和；每人显示已签约（当月新签合同）、完成率、是否落后于当月时间进度、还差多少，以及按赢率加权的商机预测。销售只看自己，管理员只读查看全公司。

## 批量导入客户

客户页「批量导入」：下载模板，填好后选 CSV（UTF-8 / GBK 都行）或 Excel，先预览——已存在的客户、文件里重复的、填错的行会标出来并跳过，名称相似的给提示——再确认导入。一次最多 1000 行。主管的模板多一列「负责人」，可以填本团队成员或「公海」。

## 定时任务

core 启动后每 30 秒检查一次，到点自动运行（北京时间），管理员在「系统设置 → 定时任务」里开关、改时间、立即运行、看运行记录：

| 任务 | 默认 | 做什么 |
|---|---|---|
| 任务到期提醒 | 开，08:30 | 今天到期的任务提醒负责人；最近一周逾期的各提醒一次 |
| 回款逾期提醒 | 开，09:00 | 逾期的回款期次提醒合同负责人和团队主管 |
| 商机停滞提醒 | 开，09:00 | 超过业务规则停滞天数的商机提醒负责人 |
| 日报催交 | 开，18:00，仅工作日 | 提醒还没提交日报的销售 |
| 公海自动回收 | **关**，02:00 | 超过 N 天（默认 90）没有跟进、没有进行中商机的客户退回公海；会改负责人，开启要确认 |

每个任务一天只跑一次（多实例也一样）；core 在运行时间没启动时，当天启动后补跑。站内提醒都有去重。企业微信群推送需要在「消息推送」里另外勾选，默认不推。`SCHEDULER_ENABLED=false` 关闭调度（只读副本、测试）。

## 通过 Nginx 访问

```bash
docker compose --profile prod up -d       # 额外启动 nginx，访问 http://127.0.0.1:8080
```

公网部署：设置 `NGINX_PORT=80`，修改 `JWT_SECRET`、`GATEWAY_INTERNAL_KEY`、`POSTGRES_PASSWORD`，设置 `MODEL_KEYS_SECRET` 和访问口令 `ACCESS_CODE`（同一 IP 连续错 10 次锁 10 分钟），只对外暴露 nginx。完整步骤（HTTPS、自动重启、空库建第一个管理员、备份与恢复）见 [上线部署指南](上线部署指南.md)。
