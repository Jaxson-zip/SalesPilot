## 0. 一句话结论

**工程骨架、业务系统、权限、网关、前端界面和测试都已完成，可以独立运行和联调；最大的缺口在「AI 真正接上大模型」这一段：**
- 意图路由、需求抽取、CRM 工具选择目前是**关键词规则占位**，还不是大模型的 function calling（场景 3 的硬要求）；
- 还没有配置任何真实模型 Key，契约测试全部跳过，知识库表是空的。

图例：✅ 已完成　⚠️ 部分完成 / 占位实现　❌ 未做
