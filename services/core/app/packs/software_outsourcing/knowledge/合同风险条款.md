# 合同风险条款

## 付款和里程碑
- 软件外包按里程碑回款：签约首付款、原型与 UI 确认款、上线验收款、质保尾款，比例和日期在行业包「里程碑回款计划」里设置。
- 每个里程碑写清楚「完成标志」：例如原型确认以客户在原型上签字为准，上线以正式环境可访问为准。
- 首付款到账后再开工；上一期款没到，可以暂停下一阶段工作，合同里写明暂停期间工期顺延。
- 客户问「能不能做完再付」：说明首付款用于锁定人员排期，可以降低首付比例，但不建议零首付。

## 工期顺延的情形
合同里写明以下情况工期相应顺延，不算乙方违约：

- 客户没有按时提供资料、素材、测试账号、接口文档。
- 客户确认原型、UI 或验收超过约定期限。
- 需求变更（按变更单约定的工期影响）。
- 付款逾期。
- 第三方原因：小程序 / App 审核、备案、对接方接口故障。

## 维保范围要写清楚
维保期内免费的：

- 修复交付功能的缺陷（和验收标准不一致的地方）。
- 服务器故障排查、安全更新、因微信 / 系统升级导致的兼容问题。
- 少量文案、配置调整。

不在维保范围、另外报价的：新功能、改业务流程、改界面设计、数据大批量处理、客户自己改代码后引发的问题。维保期满后可以续签运维，按月计费。

## 责任边界
- 赔偿上限：乙方违约责任以已收合同款为限，不承担客户的间接损失（例如营业损失）。
- 数据安全：服务器由客户持有时，数据备份由客户负责，乙方提供备份方案；乙方代运维时写明备份频率。
- 第三方服务：短信、支付、地图、大模型等第三方服务中断造成的影响，乙方不承担责任，但配合排查。
- 内容合规：客户发布的内容、上传的数据由客户负责合规。

## 暂停和终止
- 客户中途终止：已完成的工作按里程碑或人天结算，已收款不退；源码按已付款比例交付或不交付，合同里写明。
- 客户长期失联：书面通知后超过约定天数（例如 30 天）没有回应，乙方可以暂停项目，再次启动时重新排期。
- 乙方原因无法继续：退还未完成部分的费用，交付已完成部分的源码和文档。

## 签约前检查清单
- 需求清单 / PRD 作为合同附件，双方签字。
- 报价单、三档中选的哪一档、不含的费用写清楚。
- 里程碑、付款比例、每期完成标志。
- 验收标准、验收期限、逾期视为通过。
- 源码归属、交付物清单、账号主体。
- 维保期限和范围、续保价格。
- 变更流程和计价方式。
